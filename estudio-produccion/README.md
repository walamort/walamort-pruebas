# Estudio de producción Walamort

A same-origin production workspace joining existing tools without merging their project formats. Seven explicit areas share two lazily loaded frames: mixing/mastering/learning and the existing rhythm/arrangement/recording/spatial studio. Frames retain their in-memory audio during area switches. Each switch sends a validated same-origin pause command. The child validates both origin and parent source; the host validates the ready sender before routing a view. No microphone request occurs on load.

Mixing app version 1.6 accepts lab/master/learn entry views. The public website menu and discovery index link this studio. Original standalone URLs and deep links remain available. Header links escape frames to prevent recursive embedding.

Audio is local; originals must be reselected after closing. Separate tools retain separate project formats and export limits. Spatial tools are educational, not Atmos encoding. Mastering presets are not automatic LUFS normalization. Existing preparation is bounded to 30 seconds and complementary harmonic/percussive layers, not neural instrument separation.

Validation: static link/accessibility/CSP checks, existing mixing engine/DSP/library tests, browser module navigation and desktop/mobile layout. Recording UI tested without requesting microphone access; physical recording and calibrated multichannel hardware were not tested.
