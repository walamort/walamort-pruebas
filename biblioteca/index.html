Biblioteca Walamort

Materiales originales para lectura, ritmo, dictado y armonía. Prepara una ficha, úsala en pantalla o descárgala para abrirla e imprimirla sin conexión.

Preparar ficha

Activa o desactiva las soluciones antes de imprimir. Puedes usar la opción de guardar como PDF del diálogo de impresión de tu navegador.

Para preparar clases

El enlace conserva tipo, nivel, tonalidad, cantidad y código: otras personas obtienen los mismos ejercicios. Las soluciones están disponibles para consulta; úsalo como práctica abierta, no como examen reservado. No crea grupos ni registra resultados de otros estudiantes.

Abrir ficha del estudiante · Abrir solucionario

Estos enlaces mantienen los mismos ejercicios y eligen si se muestran respuestas. Las soluciones siguen siendo públicas; la ficha del estudiante no es un examen protegido.
