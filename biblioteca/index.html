Para preparar clases

El enlace conserva tipo, nivel, tonalidad, cantidad y código: otras personas obtienen los mismos ejercicios. Las soluciones están disponibles para consulta; úsalo como práctica abierta, no como examen reservado. No crea grupos ni registra resultados de otros estudiantes.

La descarga HTML es una ficha autocontenida con pentagramas: se abre sin conexión y permite imprimir desde el navegador. El audio y la práctica interactiva están en la web.
