# Walamort Mezcla 1.0

Spanish installable offline PWA,18 lessons/3 levels,54 practice steps and18 knowledge checks. Curriculum: signal flow, digital headroom, balance/pan, EQ/Q/highpass, compression/time constants/parallel, reverb/delay, mono, mix bus and honest comparison/delivery. Completion reflects quiz comprehension, not an assessment of musical taste or a certification.

Audio lab: original four-bar C–F–G–C practice arrangement, five recorded sources (CC BY3/CC0),3 stems with faders/pan; master HP/3-band EQ/parallel compressor/reverb/eighth-note delay; bypass/mono and channel-peak meters before mono fold-down. EQ graph is filter response; compressor curve is idealized, excludes knee/timing. Not spectrum/LUFS/true-peak meters. No automatic loudness compensation or mastering. Reverb is synthetic. Pause on background.

Local progress/reflections and12 project versions. Validated JSON settings import/export; full journal export is an archive, not restorable. No audio export/import here: links to existing full production lab. No accounts, ads, microphone or analytics. First PWA load requires internet. Course translations, native APK and Play Store distribution are not part of this initial version.
