# Material del diapasón
Generado con la herramienta integrada image_gen, sin usar CLI ni API key. Es una textura creada para una ilustración interactiva, no una fotografía de un instrumento concreto.

Asset de proyecto: diapason/assets/rosewood-v2.jpg (JPEG calidad 85, 397209 bytes). Original PNG conservado en el directorio de imágenes generadas; copia de revisión en outputs/diapason-textura-rosewood.jpg.

Prompt exacto:
Create a photorealistic material texture for a real rosewood guitar fingerboard. Wide horizontal rectangular image, only a flat macro photograph of unfinished dark chocolate brown Indian rosewood timber, straight fine open wood pores and natural long subtle parallel grain running strictly LEFT TO RIGHT. Uniform focus over entire surface. Subtle warm natural lighting, restrained contrast, real microscopic fibers. No guitar, no strings, no frets, no metal, no dots, no lettering, no objects, no frame, no perspective, no vignette. Edge-to-edge wood only. This will be mapped onto an interactive musical instrument neck as a background material, so do not draw instrument hardware.
